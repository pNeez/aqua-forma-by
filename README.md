# AQUAFORMA.BY — Интернет-магазин кухонных смесителей и аксессуаров (Республика Беларусь)

Готовый сайт для магазина смесителей, кранов питьевой воды и кухонных аксессуаров, адаптированный под законодательство и логистику Республики Беларусь (ИП / ООО, цены в BYN, доставка Европочтой и Белпочтой, поддержка ЕРИП и bePaid).

## Структура проекта

* `index.html` — главная страница, каталог, карточка товара, корзина, личный кабинет покупателя и админ-панель владельца.
* `styles.css` — дизайн в стиле «Современный премиальный минимализм» (графит, светлый камень, латунные акценты), полностью адаптивный под смартфоны и ПК.
* `data.js` — стартовая база товаров (смесители 3-в-1 под фильтр, с выдвижной лейкой и водопадом, с гибким изливом, дозаторы, коландеры, аэраторы) и настройки для РБ.
* `app.js` — вся логика фильтрации, корзины, оформления заказа, личного кабинета, админ-панели, интеграции с Telegram Bot API и генератора сценариев Reels / TikTok.

## Как запустить прямо сейчас

Сайт не требует сложной установки сборщиков — просто откройте файл [`index.html`](file:///C:/Users/user/.gemini/antigravity/scratch/aqua-forma-by/index.html) в любом браузере (Chrome, Edge, Safari, Яндекс).

## Как подключить уведомления о заказах в Telegram дяде за 2 минуты

1. Откройте в Telegram официального бота `@BotFather` и отправьте команду `/newbot`.
2. Скопируйте выданный **Bot Token**.
3. Напишите вашему новому боту любое сообщение, а затем узнайте свой **Chat ID** (например, через `@userinfobot`).
4. На сайте нажмите кнопку **«⚙️ Админ-панель»** (в правом верхнем углу) -> вкладка **«Настройки ИП, Оплаты РБ и Telegram»**, вставьте Token и Chat ID и нажмите **«Отправить тест»**.

## Как выложить сайт на белорусский хостинг (hoster.by / ActiveCloud)

1. Зарегистрируйте домен в зоне `.by` или `.бел` и минимальный тариф хостинга на `hoster.by`.
2. Загрузите файлы `index.html`, `styles.css`, `data.js`, `app.js` в папку `public_html`.
3. В Админ-панели заполните реальные реквизиты ИП дяди (ФИО, УНП, адрес павильона, телефон) — они автоматически появятся в шапке и юридическом блоке подвала.
